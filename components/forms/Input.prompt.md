Standard text field. Label above, hint or error below, orange focus ring.

```jsx
<Input label="Correo" type="email" placeholder="nombre@correo.com" hint="Te contactamos en 24 h." />
```

- Labels are sentence case in Spanish. Placeholders show a real example, never repeat the label.
- `multiline` for messages; `error` for validation copy written as a fix, not a scold ("Falta el código de área").
