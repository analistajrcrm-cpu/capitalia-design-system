A pill with one squared corner — the brand's label shape, used for URLs, stage markers and small stats.

```jsx
<PetalTag tone="bone">capitalia.mx</PetalTag>
<PetalTag tone="bone" uppercase size="lg">Etapa 1</PetalTag>
```

- Default corner is bottom-right, matching every printed example. Flip it only to point away from an adjacent photo edge.
- `tone="bone"` over plum or photography; `orange` for a single emphatic tag; `outline` on cream when the tag is secondary.
- One petal tag per composition. It is a signature, not a chip system — use Badge for status and Tag for metadata.
